# 2026-06-29 — App Exploration Day

## App Feature Discovery

Johnny asked me to explore the SOAPaDay web app at `https://app.soapaday.com/` to understand the full user experience.

### What I Did
- Fetched the web app (Expo/React Native Web SPA)
- Downloaded and analyzed the 4.4MB JS bundle
- Extracted GraphQL queries, mutations, screen names, and features
- Documented everything in `product/app-features.md`

### Key Discoveries

**Tech Stack:**
- Expo (React Native Web) — cross-platform mobile + web
- GraphQL via Apollo Client
- Backend connected to myChelper ecosystem
- Supabase/Firebase for auth

**Core Features Found:**
1. **SOAP Journaling** — Scripture, Observation, Application, Prayer entries with full CRUD
2. **Bible Reader** — Multiple translations, verse search, Verse of the Day
3. **Reading Plans** — Enroll, pause, resume, abandon + progress tracking
4. **Streaks & Gamification** — Daily streaks, badges, achievements
5. **Church Connection** — Link to church profile, church-specific plans
6. **Social Features** — Testimonies, sharing, inbox messaging
7. **Customization** — Light/dark themes, 3 font choices, reading preferences
8. **Offline Support** — Local cache, sync when online
9. **Export/Print** — Journal export functionality

**Fonts:** Inter (UI), Merriweather (reading), Playfair Display (headings)

**Tab Structure:** Home → Bible → Journal → Profile
