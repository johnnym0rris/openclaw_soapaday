# SOAPaDay Color Palette

## Primary Colors

| Name | Hex | Usage |
|------|-----|-------|
| **Warm Cream** | `#FAF7F2` | Backgrounds, light areas |
| **Deep Navy** | `#2C3E50` | Primary text, headers |
| **Soft Sage** | `#8BA888` | Accents, nature/wellness feel |
| **Warm Gold** | `#D4A574` | Highlights, CTAs, verse emphasis |

## Secondary Colors

| Name | Hex | Usage |
|------|-----|-------|
| **Blush** | `#E8C4B8` | Soft accents, Pinterest aesthetic |
| **Charcoal** | `#34495E` | Body text |
| **White** | `#FFFFFF` | Text on dark backgrounds |
| **Light Gray** | `#ECF0F1` | Dividers, subtle backgrounds |

## Aesthetic Direction

- Warm, paper-like textures (journaling feel)
- Soft natural light photography
- Minimal, clean typography
- Handwritten-style accents sparingly
- Nature elements: plants, coffee, morning light, open journals

## Image Generation Prompts

When generating images with AI, use these colors:
```
Colors: warm cream (#FAF7F2) background, deep navy (#2C3E50) text, soft sage (#8BA888) accents, warm gold (#D4A574) highlights
Style: warm, reflective, aesthetic Bible journaling, soft natural lighting, minimalist
```
